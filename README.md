# MBTI Step 2 Short Scale (HTML5 & VB.NET WinForms)

A non-commercial academic tool for self-exploration, based on Carl Jung's psychological type theory and MBTI Step 2 framework (see [Important Disclaimer](#important-disclaimer) for more details).

## Description

This application provides a **short-scale assessment** (40 questions) of Jungian cognitive functions (Se/Si/Ne/Ni/Te/Ti/Fe/Fi). Unlike traditional MBTI Step 1 assessments that focus on simple four-dimensional labels, this tool examines your **Cognitive Function Stack** to help you understand the psychological mechanisms behind your thinking preferences.

Additionally, the project uses .NET 8.0 SDK for backward compatibility. If you are using .NET 10.0, change the `<TargetFramework>` element to `net10.0-windows` in the VB.NET project file.

> **Note**: This project is for educational and self-exploration purposes only. The MBTI framework and Jungian psychological type theory are intellectual properties of their respective owners.

## Features

- **40 situational questions** across 8 cognitive function dimensions
- **Visual results display** with function strength charts
- **Cognitive function stack analysis** (Dominant, Auxiliary, Tertiary, Inferior)
- **Detailed interpretations** based on Jungian theory
- Available as both **HTML web version** and **Windows Forms desktop application**

## Assessment Structure

The assessment evaluates 8 cognitive functions:
- **Se** - Extraverted Sensing
- **Si** - Introverted Sensing  
- **Ne** - Extraverted Intuition
- **Ni** - Introverted Intuition
- **Te** - Extraverted Thinking
- **Ti** - Introverted Thinking
- **Fe** - Extraverted Feeling
- **Fi** - Introverted Feeling

Each dimension has 5 questions, totaling 40 questions.

## Installation & Usage
```bash
git clone https://github.com/Pac-Dessert1436/MBTI-Step-2-Short-Scale.git
cd MBTI-Step-2-Short-Scale
```

### HTML Web Version
Simply open `MbtiStep2_EN.html` in any modern web browser.

### Windows Forms Application
1. Open the solution in Visual Studio 2022/2026, or Visual Studio Code.
2. Build and run the project:
    - For VS Code, use the commands `dotnet build` and `dotnet run`.
    - For Visual Studio, click "Run" button or press F5.
3. Complete the assessment following the on-screen instructions
